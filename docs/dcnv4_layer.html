C=N Constraint

DCNv4 is a spatial aggregation layer in this implementation: output channels are forced to match input channels.

d_stride Note

The public config describes sparse offset fields, but the current GPU note says spatial d_stride downsampling is still a TODO; kernel d_stride is channel ILP.
