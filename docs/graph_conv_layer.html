Credit Assignment Overlap

One input pixel can receive gradients through several neighboring output stencils, so local messages overlap like convolution but carry adaptive edge weights.

Backward Summary

Gradients flow through activation and BN, split over self and neighbor projections, pass through aggregate weights, and finally distribute to every overlapping KxK neighborhood sample.
